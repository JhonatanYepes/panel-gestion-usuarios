# Panel de Gestión de Usuarios

Aplicación web desarrollada como actividad académica para gestionar usuarios mediante una interfaz sencilla, organizada y adaptable a diferentes tamaños de pantalla.

## Descripción del proyecto

El Panel de Gestión de Usuarios permite consultar y administrar información de usuarios obtenida desde una API REST pública. Incluye funcionalidades para buscar, registrar, editar y eliminar usuarios.

## Funcionalidades

- **Consulta de usuarios:** carga de datos desde la API JSONPlaceholder.
- **Búsqueda por nombre:** filtrado de usuarios mientras se escribe.
- **Registro de usuarios:** formulario con validación de campos e identificación única.
- **Edición de usuarios:** modificación de los datos de un usuario existente.
- **Eliminación de usuarios:** opción para eliminar usuarios con confirmación.
- **Tabla dinámica:** actualización de los resultados según las acciones realizadas.
- **Diseño adaptable:** interfaz preparada para computadoras, tabletas y celulares.

## Tecnologías utilizadas

- HTML5 para la estructura.
- CSS3 para los estilos y el diseño adaptable.
- JavaScript para la lógica, los eventos y la manipulación del DOM.
- Fetch API y JSONPlaceholder para la consulta de datos.

## API utilizada

[JSONPlaceholder](https://jsonplaceholder.typicode.com/users)
